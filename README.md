# Eastern Cape Research Dashboard
### Live Data App | Python, Pandas, Streamlit

Interactive research dashboard built during UCT Coding Summer School 2026, showcasing Eastern Cape data analysis and researcher profiling.

**🔗 Live Demo:** https://css2026-celokuhle.streamlit.app  
**👨‍💻 Author:** Celokuhle Sandise Ntete | Data & Software Developer

---

### Features
- **Researcher Profile** - Professional profile with tech stack
- **Research Publications** - CSV upload, keyword filter, publication trends chart
- **Data Explorer** - Interactive analysis of:
    - Population & Unemployment by District
    - Education Levels distribution
    - Monthly Rainfall trends
- **Contact** - Professional contact integration

### Tech Stack
- Python
- Pandas & NumPy
- Streamlit
- Data Visualization (Bar Chart, Area Chart)
